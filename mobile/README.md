# Phone app shell (iPhone and Android)

A small native app, made with Capacitor, that opens the live site
(`server.url` in `capacitor.config.json`). The web app stays the one place
where features are built; this folder only holds the native wrapper.

- `ios/` and `android/` are generated by Capacitor. Edit them only for native
  settings (icons, permissions, push).
- CI (`.github/workflows/mobile.yml`) builds both, unsigned, whenever this
  folder changes. No Mac is needed.
- The app name must match `src/design/brand.ts`; a unit test checks it.
- Icons, splash screens and `www/offline.html` are made from the brand by
  `npm run app-assets` (from the repo root). Re-run it after a brand change.

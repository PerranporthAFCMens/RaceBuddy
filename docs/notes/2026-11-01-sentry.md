# 2026-11-01: Crash alerts with Sentry

- Browser: `@sentry/browser` set up in `src/instrumentation-client.ts`; `error.tsx` and `global-error.tsx` report what they catch. Errors only (no tracing, replay, clicks, headers, cookies, IP or query strings).
- Server: `src/instrumentation.ts` `onRequestError` sends a plain Sentry envelope (`src/lib/monitoring.ts`), no extra package. `@sentry/nextjs` was not used: it pulls in build plugins with known moderate vulnerabilities, which the security check (rightly) refuses.
- Only the dev and live sites report (`NEXT_PUBLIC_SITE_ENV`). The DSN is in the code on purpose: it is public (every browser gets it) and only allows sending reports.
- `/api/sentry-test` crashes on purpose on the dev site, 404 elsewhere.
